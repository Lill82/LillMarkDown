From PDF to Markdown, by drag and drop.

LillMarkDown is a free, open-source Windows app that turns PDF files into clean Markdown: with headings, paragraphs and lists, and without running headers or page numbers.

Download for Windows Source code

Windows 10/11 (64-bit) · A single executable, nothing to install · AGPL-3.0 licence

How it works

Three steps, no setup.

  1. Drop

    Drop one or more PDFs on the window, or a whole folder (subfolders are converted too). You can also click to pick them.

  2. Convert

    It reads the size and weight of the type on each line to tell headings, paragraphs and lists apart.

  3. Done

    A .md file with the same name appears next to each PDF. Nothing is overwritten unless you ask.

What it does

Made for reusing documents in Markdown editors, wikis or AI tools.

Headings by size

The largest font sizes become #, ## and ###. Short bold or all-caps lines become a subheading.

Whole paragraphs

Rejoins wrapped lines and words split by a hyphen at the end of a line.

Lists

Bullets (•, –), numbers (1., 1)) and letters (a)) become Markdown lists.

No clutter

Repeated headers, footers and page numbers are dropped. Pages are separated with ---.

Batch mode

Converts dozens of files at once, folders included, showing progress file by file.

Clear warnings

Tells you when a PDF is scanned (it has no text) or password-protected.

Requirements

  • 64-bit Windows 10 or 11.
  • Nothing else: the executable carries everything it needs.
  • The app's interface is in Catalan.
  • The first time, Windows SmartScreen may show a warning because the executable isn't signed. Click More info, then Run anyway.

Limitations

  • Scanned PDFs contain only images, no text: run them through OCR first.
  • Tables and multi-column text are converted line by line, without table structure.
  • Files are processed on your computer; nothing is sent over the internet.
